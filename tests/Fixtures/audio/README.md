# Audio fixtures

`jfk.wav` is the approximately 11-second JFK inaugural-address sample distributed
with the MIT-licensed [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
project. The underlying 1961 United States presidential address is a United
States government work. It is retained as an unmodified, fixed speech-recognition
benchmark fixture.

Expected transcripts live in the adjacent `../transcripts` directory. Do not
replace or regenerate golden files automatically.
